# SELENE · 月面战术自走棋

[English](README.md) · 简体中文

一款可在浏览器运行的轻量近未来月面 PVE 自走棋。玩家自由选择兵种、部署阵型并预设战斗命令，随后观看部队自动交战。

## 当前内容

- 四个可连续闯关的任务：静海防线、陨石坑群、第谷中继站、高地堡垒；每关有战术提示，获胜后可前往下一关。
- 四种不同部署方式：宽正面、坑群双翼、工业站 L 形集结区、堡垒内院；堡垒采用平整台地，中继站使用整平工业地面，通信前哨只出现在第一关。
- 四关共用初始 140 资金，从第一关空编队开始，购买部队扣款，关卡间不补款。胜利后幸存单位满状态进入下一关，挑战更低总花费。
- 第四关为两波五方向防御战，22 名混编敌军；我军依托扩建护墙、四角塔楼、双联炮位和北侧指挥堡击退围攻。
- 中继站包含连续混凝土基地、外围建筑、道路管网和巨型设施。
- 十种兵种，包含步兵、狙击、导弹、履带无人车、二足机甲、四足坦克与火箭炮。
- 平面防重叠站位、质量碰撞、方向性装甲与盾兵驻定近战。
- 高地、掩体、松软月壤、战壕、桥梁和围栏通行规则。
- 二足机甲与四足坦克可直接跨越战壕，其他单位需要走桥或绕行。
- 两个固定相机及自由环绕、缩放、平移。
- 战前命令、自动战斗、暂停、两倍速度与本次战役花费结算；刷新页面后重新开始。
- 开场按地形、战场、兵种图鉴、界面四个实际准备阶段加载；部署教学随选择、放置、调整和命令操作推进，可随时点 × 跳过。
- 寻路会检查整段路线与单位占地，自动绕开建筑、岩体与陡坡；不可达目标不会退回穿墙直行。
- 本地程序化模型、迷彩材质、攻击特效和 Web Audio 音效，无外部素材请求、无后端依赖。
- 分层交火视效：枪口闪光与尾焰、狙击轨道残像、分叉电弧、三层火舌、火箭尾迹、多火球爆炸、碎屑、冲击环、烟柱和焦痕。
- 重武器模型动作：坦克炮管后坐与炮塔回弹、火箭炮发射架回弹、导弹筒短促后坐，开火后平滑精确复位。
- 正式视觉版本为 25 色像素渲染、4×4 有序抖动、像素兵种缩略图与硬边指挥界面，已替换旧版连续色调，不再提供 `art=original` 回退入口。

## 环境要求

推荐 Node.js 22.12 或更高版本。项目使用 TypeScript、Vite 和 Three.js。

## 本地启动

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。每次打开或刷新页面都从第一关空编队开始，不读取或写入本地存档。

加载完成后自动开始部署教学。教学窗口跟随对应兵种、站位和命令面板；点窗口右上角 **×** 或按 **Escape** 跳过，战前可从右上角 **? → Replay tutorial / Reabrir tutorial / 重新打开教学** 再次打开。教学直接使用本次战役的正常部署操作，不自动购买单位或启动战斗。刷新后教学会再次出现。流程与验收见 [开场与教学](docs/onboarding.md)。

macOS 也可以双击项目中的 `启动试玩.command`，自动启动并打开本地网页。关闭终端或按 `Control+C` 停止服务。

战役必须依次通过静海防线、陨石坑群、第谷中继站、高地堡垒（两波防御战）。顶部 01–04 显示进度，不能跳关；`mission` 参数也不能绕过进度。编辑器可使用 `?editor=1&mission=craters` 等链接独立研究地图。

## 战役经济与继承

- 四关共用 **140** 初始资金，没有过关奖金或自动补款；兵种标价就是购买金额，没有每关人口配额。
- 第一关没有友方默认单位。点击兵种卡片购买并放置，开战前可调整位置与战术。
- 本关新兵撤回时全额取消购买；继承老兵撤回后进入预备队，不返钱，可免费再次部署。「撤回全部」同时取消新兵购买并收回老兵。
- 胜利后按顺序继续，阵亡者移出战役，幸存者恢复生命、冷却及异常状态；已有战术保留，可在新地图重新布阵。预备队不会参战或阵亡。
- 失败、重新试战或中止交战会恢复本关开战前的完整编队，不重复收费。获胜后重试本关也不会叠加收益或推进两次。
- 最终结算显示本次总花费与余额，可重新开始挑战更省钱的打法，不保存历史成绩。
- 资金与部队仅在当前页面内存中保留，关卡间切换不刷新页面；关闭、刷新或离开游戏页面后进度清空。

规则、寻路改动与连续模拟结果见 [战役经济与寻路](docs/campaign-economy.md)。地图与部署差异、堡垒改造和验收边界见 [地图差异化](docs/map-differentiation.md)，回归命令为 `npm run test:maps`。

## 游戏语言

本地版支持 **English**、**Português (Brasil)** 和 **简体中文**，上传版只支持前两种。默认使用英语，葡语浏览器使用巴西葡语；不保存语言偏好，当前选择只反映在页面和链接的 `lang` 参数中。切换时保留部署、战斗进度、暂停/倍速状态、编辑内容和未提交的属性输入。

可以在任务链接中指定语言，例如 `?mission=tranquility&lang=en`、`?mission=tranquility&lang=pt-BR`，编辑器使用 `?editor=1&lang=pt-BR`。显式链接优先于浏览器语言，后续任务和编辑器链接会携带当前语言。上传版不接受 `lang=zh-CN`。

界面、四关简报、兵种与战术说明、操作手册、结算、编辑器校验及战斗记录均已翻译。玩家填写的关卡名称与导入/导出的 JSON 数据保持原样。

翻译与切换回归检查：`npm run test:i18n`。实现与验收范围见 [多语言说明](docs/localization.md)。

## 离线试玩

如果目录中已有 `试玩.html`，用 Chrome、Edge 或 Safari 直接打开即可游玩，不需要启动服务器。离线版同样从第一关开始，保留共享资金、单位继承和语言切换。

重新生成这个单文件版本：

```bash
npm run build:offline
```

游戏需要浏览器支持 WebGL 2。初始化失败时，加载页会显示错误说明和重新加载按钮。

## 构建与预览

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。Vite 使用相对资源路径，可部署到 GitHub Pages 等静态网站托管服务。将 `dist/` 内容发布即可，无需服务器端路由。

Cloudflare 上传版使用 `npm run build:public`，输出到 `dist-public/`，仅提供英语和巴西葡语。已打包的 `selene-cloudflare.zip` 可用于 Pages 手动上传，步骤见 [Cloudflare 发布操作](docs/cloudflare-deploy.md)。

## 数据行为

游戏无登录、后端、数据库、统计脚本或玩家数据上报，不读取或写入 localStorage、sessionStorage、IndexedDB 或 Cookie。战役、成绩、语言选择和编辑器内容均不自动存盘；手动 JSON 导入/导出是玩家明确发起的文件操作。浏览器仍可能缓存网页静态资源，托管平台自身的访问日志由平台管理。

## 关卡编辑器

在游戏顶部点击 **关卡编辑器**，或在本地地址后加 `?editor=1`。离线 `试玩.html` 也包含编辑器。

- **地形**：放置高地、陨石坑和松软月壤，调整位置、半径、高度或深度。高度、视野、射界和移动减速使用编辑后的地形计算。
- **建筑**：放置岩体、防御墙、掩体堡、货柜和雷达站；可移动、旋转和改变尺寸。建筑会阻挡单位；低矮工事提供掩护，高大建筑阻挡直射视线。雷达站为实体设施，不额外提供探测加成。
- **兵力**：双方均可在全图放置十种兵种。选中单位后可修改阵营、兵种、坐标、朝向、行动方式和目标优先级。
- **任务设置**：编辑任务名称、我方部署预算和时间上限。支持空白月面及四种场景模板；模板保留独立测试用参考编队，不读取或消耗战役资金。
- **试战调试**：一键从当前编队开始单波歼灭战；支持暂停、单步 `1/30` 秒、`0.5× / 1× / 2× / 4×` 速度、重新试战和返回编辑。监视面板显示选中单位的生命、目标、坐标、冷却、战术及伤害，并记录摧毁与结算事件。试战结束后草稿保留完整编队。
- **检查与历史**：试战前检查双方编队、补给超额、单位重叠和障碍冲突。支持 40 步撤销/重做；载入模板和导入关卡也可撤销。
- **手动导入/导出**：通过 JSON 文件传入或传出地图与战术配置。不自动保存浏览器草稿，刷新后编辑内容清空。

编辑器操作：左键放置或选择、拖动对象；`V` 选择、`X` 橡皮、`R` 旋转 45°、`Delete` 删除；`⌘/Ctrl+Z` 撤销、`⇧⌘Z / Ctrl+Y` 重做、`⌘/Ctrl+Enter` 试战。试战中空格暂停，`.` 单步。文字输入时不会触发地图编辑快捷键。

当前每张地图最多 80 个双方单位、40 个地形区域、64 个建筑/岩体。地图范围为 `X: -36…36 m`、`Z: -30…30 m`。编辑界面适合桌面鼠标和键盘操作。

逻辑回归检查：

```bash
npm run test:editor
```

检查覆盖关卡文件校验、手动 JSON 往返、历史记录、地形效果、旋转建筑碰撞/遮挡、寻路、四种自定义模板和四个原任务。三维显示需在支持 WebGL 2 的浏览器中验收。

盾兵与碰撞回归检查：`npm run test:battle`。盾兵接近敌人后停步近战，按原有伤害与间隔攻击；接触阻挡和拥挤修正不会把移动持续传成推力。检查覆盖追击后排时的近身接战、友军挡路、后排挤压、隔着友军传递挤压、绕行、撤退、攻击间隔与目标死亡后重新推进。

关卡挑战与兵种定位的研究、调整依据和模拟结果见 [1–4 关挑战递进](docs/campaign-progression.md)。坦克消耗 8 补给；导弹兵生命为 150，对坦克、机甲穿透一半装甲减伤；火箭炮丢失观察后会前移搜索。

连续四关经济分析：`npm run analyze:economy -- --seeds 24 --output /tmp/selene-economy.json`。会从同一笔资金购买、继承幸存者再补兵，不在关卡间重置资金。

独立地图参考编队分析：`npm run analyze:campaign -- --seeds 24 --output /tmp/selene-campaign.json`。可通过 `--missions bastion --profiles default,tanks` 缩小范围。这里的编队仅为测试输入，不会出现在战役中。模拟表现不能当作玩家胜率。

经济与寻路回归：`npm run test:campaign`、`npm run test:navigation`。

## 操作

- 点击兵种卡片，再点击青色部署区放置单位。
- 左键拖动调整站位，`R` 旋转，`Delete` 撤回。
- 选中单位后，在底部设置行动方式与目标优先级。
- `1 / 2 / 3` 切换战术、前线和自由相机。
- 右键环绕、滚轮缩放、中键平移。
- 空格暂停，开战前可按 `Enter` 开始战斗。

```text
src/
  main.ts          游戏与编辑器入口
  game.ts          页面、部署和任务交互
  editor.ts        三维编辑、属性面板、试战调试和草稿
  editor.css       编辑器布局和控件
  level.ts         关卡格式、模板、导入校验、保存和历史
  level-validation.ts  编队与试战检查
  map-objects.ts   自定义地形与建筑的模型、碰撞和射界
  dispose.ts       替换场景时释放三维资源
  battle.ts        战斗模拟、AI、伤害和碰撞
  terrain.ts       连续月面、战壕、寻路和设施
  bastion.ts       第四关护墙、塔楼、指挥堡、炮位和闸门
  models.ts        程序化兵种与装甲材质
  renderer.ts      Three.js 场景、相机和单位表现
  effects.ts       弹道、爆炸、烟尘与冲击效果
  audio.ts         Web Audio 混音与武器音效
  missions.ts      四关敌军、波次、战术提示和结算文案
  campaign.ts      共享资金、购买退款与页面内战役状态
  training-formations.ts  编辑器及自动模拟用参考编队
  data.ts          兵种数据与战斗参数
  thumbnails.ts    真实模型缩略图渲染与色板量化
  pixel-art-preview.ts  像素渲染管线与 25 色色板
  style.css        指挥界面基础样式
  pixel-ui.css     像素风指挥界面与编辑器视觉覆盖
```

## GitHub 源码包

`selene-github-source.zip` 是适合上传仓库的源码包。解压后上传其中的项目内容，包含源码、测试、构建脚本、锁文件、英文说明和中文详细说明。打包与上传步骤见 [GitHub 源码发布](docs/github-release.md)。

```bash
npm ci
npm run dev:public
```

`dev:public` 和 `build:public` 使用英语与巴西葡语。普通本地开发 `dev` 与本地构建 `build` 保留原有中文选项；公网发布使用 `build:public`。

源码包不包含依赖目录、编译结果、试玩 HTML、Cloudflare ZIP、个人工具配置、提示词或旧制作截图。离线试玩可通过 `npm run build:offline` 重新生成，最新地图几何诊断图保留在 `art-direction/map-differentiation/`。

## 已验证的依赖版本

根依赖固定为本机实际运行并通过检查的 Three.js 0.186.1、@types/three 0.186.0、TypeScript 7.0.2 和 Vite 8.3.4。锁文件补齐全部包的下载地址与完整性哈希，并在独立目录以 `npm ci` 重装检查。它们不表示上游最新版本；本次没有重新查询漏洞数据库。日后升级请同时更新清单与锁文件并重新验证。
