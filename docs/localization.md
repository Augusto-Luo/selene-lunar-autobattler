# 游戏多语言

本地版支持英语 `en`、巴西葡语 `pt-BR` 和原有简体中文 `zh-CN`；`npm run build:public` 生成的上传版仅提供 `en` 与 `pt-BR`，拒绝中文语言参数。游戏与关卡工坊共用顶部语言菜单，可在部署、交战、暂停、结算和试战中即时切换，不重新创建战场。

进入页面优先使用链接 `lang` 参数，否则葡语浏览器使用巴西葡语，其余使用英语。语言菜单更新当前地址，不读取或写入浏览器存储。浏览器限制 `file://` 历史更新时，切换仍可使用，任务与编辑器导航链接继续携带语言。

## 翻译范围

`src/i18n-messages.ts` 集中保存原文、英语和巴葡语。`src/i18n.ts` 负责文本、插值、属性、语言偏好、导航和切换通知。兵种及四关简报通过 getter 读取当前语言；兵种 ID、战术 ID 和战斗数值不随语言变化。

战斗内部状态保持稳定，展示时翻译。增援事件携带消息键与参数，战斗记录和可见校验错误在切换时重新格式化。编辑器切换前暂存输入值，刷新文案后恢复，不提交属性、更改历史或触发存档。玩家命名、编辑草稿及 JSON 字段与取值不被翻译。

UI 延续现有像素界面；英语和葡语较长的兵种名允许换行，较窄的窗口将游戏顶栏排列成两行。

## 验证

- `npm run test:i18n`：两种译文非空、无中文残留、插值一致；兵种/战术/四关文案实时切换；数值不变；关卡 JSON 保留；网址/浏览器语言优先级；存储零访问；已有错误提示切换。
- `npm run test:public`：上传版只有英/巴葡选项、中文参数不能启用中文、语言初始化不接触存储。
- `npm run test:editor`：12 项编辑器、关卡、手动 JSON、寻路及原任务回归。
- `npm run test:battle`：16 项盾兵、火箭炮及破甲回归。
- 当前上传版完成 15 条 DOM 流程检查：英语和巴葡界面、购买退款、连续四关继承、刷新清空、编辑器修改/试战/语言切换、中文入口关闭，全程浏览器存储访问次数为零。地图及战斗逻辑真实运行，WebGL 渲染、缩略图、音效和像素后处理使用替身。
- `npm run build:offline`：生成 `dist/` 与可直接打开的 `试玩.html`。

当前环境无法启动可交互的 WebGL 浏览器，尚未完成真实浏览器的语言菜单操作和英语/葡语长文案画面验收。
