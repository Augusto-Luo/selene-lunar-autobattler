# 开场加载与部署教学

沿用当前像素指挥界面的深紫背景、青色指引和琥珀色主按钮。一个教学窗口配一个高亮目标，玩家仍可直接操作兵种和战场。

## 加载

加载页的基础样式写在 HTML 中，脚本准备前即可显示。进度按真实初始化阶段推进：月面地形与模拟 → 战场渲染 → 兵种图鉴 → 指挥界面。准备工作之间让浏览器绘制画面，首次战场帧绘制后再解除界面锁定；没有计时器伪造的百分比。编辑器同样使用加载页，但不自动开启战役教学。

初始化失败会保留加载页，显示 WebGL 2 提示与重新加载按钮。进度条有可访问标签，准备中的游戏区域保持 inert 和 aria-busy。

## 教学

1. 选择兵种：高亮枪兵，其他兵种也可继续；只选择不扣款。
2. 放置单位：标记一个可用站位。只有合法放置才前进，正常扣款。
3. 调整排布：拖动友军到另一个合法位置，或旋转朝向。也可选择保留当前站位。
4. 设置命令：点行动方式或目标优先级，也可保留当前命令。
5. 完成：提示继续组建部队、140 共享资金和幸存继承；由玩家自行开战。

每一步右上角均有 ×；Escape 也可跳过。右上角 ? 操作手册提供重新打开入口，已有部队时从调整站位继续。帮助和重开确认弹窗暂时隐藏指引，返回后继续；开战或进入下一关时关闭指引。删除唯一的单位会回到兵种选择，不生成替代单位。

指引跟随相机、窗口大小和滚动位置，选取不覆盖目标且留在窗口内的位置；教学窗口可滚动，关闭按钮保留在窗口中。兵种和命令区域会在进入对应步骤时滚入可见范围。仍以游戏现有桌面鼠标键盘布局为主。

教学进度只存在于页面内存中，不记录已读状态，刷新后从第一关重新教学。上传版提供英语和巴西葡语，本地版另有中文；切换语言保留教学步骤、编队和余额。

动效包含加载条阶段过渡、加载页淡出、教学窗口短距离出现与跟随目标移动、站位标记的像素闪烁。系统开启减少动态效果时禁用这些动画。

## 检查

- `npm run test:onboarding`：4 项位置约束检查，覆盖兵种、站位、底部命令、开始按钮、四角、窄窗口和移出视野的目标。
- `npm run test:i18n` 与 `npm run test:public`：完整翻译与上传版语言限制。
- DOM 集成检查使用真实 HTML、游戏部署、经济和地形逻辑，仅替换 WebGL、缩略图与音频：21 项流程覆盖加载等待绘制、错误恢复、淡出与减少动态效果、英葡完整操作、非法站位、取消拖动、旋转、关闭/重播/帮助、语言切换、删除退款、正常开战和刷新重置。持久化接口访问次数为 0。
- 最终交互版本连续运行 3 次通过，最后一轮输出见 [检查记录](checks/onboarding-dom.txt)。
- 原有 15 项上传版 DOM 流程继续验证四关资金、幸存者继承和无存储编辑器。
