# 1–4 关挑战递进：研究与首轮调整

本文保留经济系统改造前的研究与数据。当前战役已改为四关共享资金、空编队开局与幸存者继承，寻路也已更新；当前规则及模拟结果见 [战役经济与寻路](campaign-economy.md)。本文中的默认编队与每关配额仅对应历史版本。

已将四关整理成「基础阵型 → 地形与曲射 → 混编破甲 → 多方向连续防御」。沿用现有地图、建筑和像素视效，主要调整默认编队、补给预算、战术与敌军分工，并小幅修改坦克、导弹兵。

## 原来的问题

用真实地形、寻路和战斗逻辑进行 256 场自动对战：默认编队每关 24 个种子，其余五种策略每关各 8 个种子。

| 关卡 | 默认编队获胜 | 结算时间中位数 | 剩余有效战力中位数 |
| --- | --- | --- | --- |
| 01 静海防线 | 24/24 | 57.5 秒 | 50.4% |
| 02 陨石坑群 | 24/24 | 27.7 秒 | 61.1% |
| 03 第谷中继站 | 24/24 | 39.6 秒 | 44.3% |
| 04 高地堡垒 | 0/24 | 130.4 秒 | 0% |

- **第二关比第一关轻松。** 首关默认大量驻守单位不主动接敌；移除火箭炮后 0/8 获胜，全军推进却能 8/8 获胜。初见玩家面对的是不明显的命令依赖。
- **第四关的默认部署与防守目标脱节。** 全驻守容易被墙体与射界分割，默认 0/24；全军推进、纯坦克各 8/8 获胜。
- **重甲性价比过高。** 纯坦克四关均 8/8 获胜，第三、四关损失补给中位数只有 10%、9.1%。导弹兵 130 生命会被一发坦克炮击倒，反装甲定位难以发挥。
- **存在无效等待。** 第四关默认编队有 9/24 场在长期停火后超时。火箭炮失去观察单位后没有搜索目标，南路单位也可能卡在城墙与地图边缘之间。

首关只简化预设，十种兵种仍可自由选择。第二关移除火箭炮的测试编队也能通关，但会承担更多消耗；第三关进一步检验兵种配合，第四关将此前出现的要求组合到连续作战中。第四关继续使用现有两波歼灭规则，建筑没有新增耐久或占领判定。

每关已显示训练重点、目标与战术提示；前三关胜利后提供“下一关”入口。第三关结算文案也会指向第四关。

## 兵种的小范围调整

| 项目 | 调整前 | 调整后 | 目的 |
| --- | --- | --- | --- |
| 坦克补给 | 7 | 8 | 为兼具射程、装甲与越壕能力的平台付出相应成本 |
| 导弹兵生命 | 130 | 150 | 可承受一次约 140.6 伤害的坦克直击，保留反击机会；连续受击仍会阵亡 |
| 导弹对重甲 | 使用普通爆炸减伤 | 对坦克、机甲的装甲减伤减半，包含正面装甲 | 让反装甲兵承担明确的重甲克制职责 |

导弹的基础伤害、射程、射击间隔和锁定时间沿用原数值。正面命中坦克约从 83 提升到 120 伤害，对步兵与盾兵的伤害规则沿用原值。双方使用同一套兵种规则。

## 同时修正的行为与站位

- 火箭炮优先攻击已被己方观察到的敌人；观察丢失后会向搜索目标移动，开火仍需要视野条件。
- 第三关一名敌方狙击兵从 `(16, -8)` 移到 `(16, -7.5)`，离开障碍内部。第二关坦克横移 `0.25 m`，使默认站位满足坡度检查。
- 第四关南路第一波从南门正后方进入，避开狭窄墙后区域，消除本轮复现的堵路超时。
- 寻路终点只保存坐标，避免把目标单位及其历史路径不断复制进新路径。这对较长的两波作战也有帮助。

盾兵保持之前修复后的停步近战与接触阻挡行为，其 11 项回归检查全部通过。

## 调整后的验证

六种策略为：默认、全部推进、全部驻守、移除火箭炮、纯狙击、纯坦克。最终配置每种每关各 24 个种子，共 576 场；第二关站位修正后单独重跑其 144 场。

| 关卡 | 默认编队获胜 | 结算时间中位数 | 剩余有效战力中位数 | 停火超时 |
| --- | --- | --- | --- | --- |
| 01 | 24/24 | 20.4 秒 | 70.1% | 0 |
| 02 | 24/24 | 31.6 秒 | 53.9% | 0 |
| 03 | 24/24 | 40.0 秒 | 42.9% | 0 |
| 04 | 19/24 | 72.2 秒 | 31.3% | 0 |

“剩余有效战力”按 `Σ(存活单位剩余生命比例 × 兵种补给) / 初始部署补给` 计算，可同时反映阵亡与幸存单位受损。它不是实时输出能力的估计。不同关卡的编队构成不同，仅看阵亡数量或阵亡补给比例会漏掉重甲承受的大量伤害；完整数据也保留了补给损失。

默认编队的战力消耗与作战时间已经逐关增长。第四关耗时增幅较大，来自两波连续作战。全部 576 场均完成结算，本轮六种策略均无长期停火超时。

几个值得继续观察的结果：

- 首关移除火箭炮仍为 24/24 获胜，默认编队本身已不含火箭炮。
- 第二关移除火箭炮为 24/24，剩余有效战力降到 38.6%；曲射提供可见收益，也保留其他解法。
- 第三关纯坦克为 24/24，但剩余有效战力只有 13.5%，补给损失 75%；默认混编分别为 42.9%、47.8%，配合的收益明显。
- 第四关纯坦克仍有 22/24 获胜，剩余有效战力为 32.0%，接近默认混编的 31.3%，耗时更长。重甲仍是可行选择，其优势尚未完全消失。
- 第四关移除火箭炮仅 2/24 获胜。该关对曲射火力依赖较强，已在前两关引入观察与曲射，并在第四关预设两门火箭炮；后续真人试玩应重点观察这一要求是否足够清楚。

这些是固定策略的自动对战结果，不能当作玩家胜率。模拟为 30 Hz，只替换了 Canvas 纹理绘制，实际地图几何、寻路、装甲与战斗逻辑均运行。种子影响初始冷却和 AI 时序，未模拟玩家理解、布阵、重试与临场观察。

可复现命令：

```bash
npm run analyze:campaign -- --seeds 24 --output /tmp/selene-campaign.json
npm run analyze:campaign -- --seeds 24 --missions bastion --profiles default,tanks
npm run test:battle
npm run test:editor
npm run build:offline
```

原始逐场指标与统一中位数统计保存在 [campaign-benchmark.json](campaign-benchmark.json)。调整前、后使用同一组种子；调整前其他策略每组为 8 场，默认及调整后每组为 24 场。中位数对偶数样本取中间两值平均。

验证通过：16 项战斗检查、13 项编辑器与原任务检查、四关 DOM 过关流程、类型检查、生产构建与离线打包。DOM 检查覆盖提示、胜利后续关、末关边界、恢复部署及失败重试，渲染与音频使用测试桩。当前环境无法运行真实浏览器，本轮没有验证 WebGL 画面或实际鼠标手感。

下一轮真人试玩应记录每关重试次数、能否理解战术提示、第二关是否能主动利用曲射或侧翼、第四关能否合理保留观察与远程火力。根据这些反馈继续调整敌军站位与兵力比例。
