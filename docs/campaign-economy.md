# 连续战役经济与寻路

四关从独立预算改为共用 **140 初始资金**，必须按 01→04 完成。第一关没有预置友军，以总花费更少完成整场战役为挑战目标。敌军、波次、兵种价格和战斗数值沿用上一轮调整。

## 购买与继承

购买成功并放置时扣款，没有过关收入。当前关卡的新兵可以取消购买并全额退款；上一关继承的老兵可以收入预备队并免费归队，不出售换钱。「撤回全部」取消新兵购买、收回老兵，不会返还老兵价值。

胜利结算确认幸存者名单，继续下一关时只保留幸存者与未参战预备队。友军保留兵种、身份、朝向和战术，恢复全部生命，清除冷却、蓄力、硬直、目标与旧路径。重新部署优先使用原布阵位置；与新地图冲突时寻找合法空位，无可用位置的老兵保留在预备队。

失败或中止交战恢复本关开战前编队，既不重复收费，也不永久扣除本次失败中的阵亡单位。胜利后重试本关会撤销这次待确认的结算，不能重复继承或叠加收益。最终结算显示本次总花费与余额，不保存历史成绩。

战役和编辑器均只在当前页面内存中保留状态，不读写本地存档。刷新游戏页面后从第一关重新开始，刷新编辑器后恢复初始模板。关卡切换复用当前 WebGL 场景容器，在当前页面载入下一张地图，因此仍可不刷新地连续通过四关。界面明确提示刷新会重新开始。

历史参考编队移至 `src/training-formations.ts`，只用于编辑器模板与自动模拟。四个正式任务的友方配置均为空，正式战役没有「默认编队」按钮，也没有每关的人口或补给配额。

## 寻路修正

- **整段占地检查**：按单位半径扫掠路线，检测圆形岩体及旋转矩形建筑，补上节点之间的薄墙、转角碰撞。矩形角使用圆形占地的真实距离，避免把可通行的角落误判为阻挡。
- **统一安全边距**：站位判断、移动约束与路线检查采用一致的占地边距，避免单位在墙边被碰撞约束推到寻路判定不接受的位置。
- **安全失败路径**：不可达时仅返回安全的接近路线或等待，不再退回朝目标穿墙直行；目标在建筑内部时不会强行追加该坐标。
- **平滑与重算**：移除多余格点转弯，但每条简化路线仍检查扫掠；接近转角时只有后续整段安全才跳点。目标明显移动或持续受阻时重算，失败后间隔尝试，避免每帧重复搜索。
- **地形与步态**：检查路线上的高度变化。步兵与履带单位走桥或绕过战壕，机甲和四足坦克保持跨壕能力。
- **移动兜底**：过大的移动步长或失效旧路径在障碍前截停，保留盾兵接触后停步近战、不能推动其他单位的规则。

导航格与边连接按地图、半径和步态缓存。编辑器应用地图修改时创建新地形对象，使用新导航缓存。

## 连续模拟

最终代码使用 24 个固定随机种子进行完整四关模拟：同一笔资金，先使用老兵，再按参考编队补齐缺少的兵种。每关没有收入，只有真实存活者恢复并继承；没有中途干预或失败重试。地图差异化改造后的最新记录见 [连续战役模拟](map-differentiation-benchmark.json)；早期地图记录保留在 `campaign-economy-benchmark.json`。

| 关卡 | 累计花费中位数 | 余额中位数 | 交战时间中位数 |
| --- | ---: | ---: | ---: |
| 01 静海防线 | 26 | 114 | 24.2 秒 |
| 02 陨石坑群 | 65 | 75 | 26.9 秒 |
| 03 第谷中继站 | 85 | 55 | 32.8 秒 |
| 04 高地堡垒 | 114 | 26 | 63.2 秒 |

参考打法 24/24 完成，通关花费 103–133，没有超过 30 秒未造成伤害的失败超时。该结果确认共享资金下存在可行打法，并不代表玩家胜率或最低可达花费；更省钱的编成与保全战术仍需试玩探索。140 给首次尝试留出余地，结算继续鼓励减少总购买额。

重跑：`npm run analyze:economy -- --seeds 24 --output /tmp/selene-economy.json`。

## 检查范围

- `npm run test:campaign`：10 项购买、退款、连续关卡、幸存者、预备队、重试、状态隔离与异常数据检查。
- `npm run test:navigation`：10 项薄墙、旋转墙、U 形建筑、封闭障碍、非法目标、大单位窄门、过桥、真实单位绕障、过大步长和失败重算检查。
- `npm run test:battle`：16 项原盾兵及兵种机制回归。
- `npm run test:editor`：12 项编辑器、模板、手动 JSON、寻路和地图回归。
- `npm run test:i18n`：10 项英/巴葡翻译、切换与原存档格式检查。
- 公网上传版完成 15 条 DOM 交互流程，覆盖英/巴葡购买退款、连续四关幸存继承与满状态、刷新重新开始、结算不落盘、编辑器刷新清空，以及中文入口关闭。全程浏览器存储访问次数为零。

DOM 检查使用真实地图与战斗逻辑，WebGL 渲染、音效和像素处理使用替身。本环境未完成真实 WebGL 浏览器的画面与手感验收。
