# 关卡工坊交付说明

设计目标：让玩家始终围绕同一张三维地图，完成「放置对象 → 修改属性 → 试战观察 → 返回调整」。

沿用 SELENE 的深色指挥界面、琥珀色主操作和青/红阵营标识。左侧为工具、对象清单和模板，中央保留最大地图区域，右侧为对象属性或任务设置；试战时收起左侧工具，右侧变为状态监视。主要操作为“试战”，退出试战后的主要操作为继续编辑。

复用现有 Three.js 程序化兵种、缩略图、光照和相机。新增建筑以同一组尺寸生成模型和旋转碰撞边界。地形使用可编辑圆形区域叠加，包含高地、陨石坑和月壤；四个模板采用可编辑预制场景并载入原任务编队。任务类型为单波歼灭战。

关键状态包括：选择、放置预览、非法站位、拖动、属性修改、撤销/重做、检查失败、草稿保存/失败、导入失败、试战/暂停/单步/结束以及返回编辑。失败的导入保留地图，保存失败保留内存草稿并提供 JSON 导出。试战使用独立模拟，不将伤亡、坐标和冷却写回草稿。

控件沿用已有按钮的按下与选中反馈；工具和表单焦点使用 100–160 ms 过渡，面板首次出现使用 180 ms 淡入，相机沿用现有过渡。开启减少动态效果后关闭编辑器的过渡与动画。高频战斗数据直接更新，避免动画干扰阅读。文案初稿已精简，保留对象名称、实际地形作用、保存状态和主动作；没有加入装饰性说明或额外图片。

桌面使用三列布局，较窄视口缩小边栏并换行头部操作，侧栏内容单独滚动。编辑器沿用项目的 720 px 页面最小宽度，主要面向鼠标与键盘。

- `npm run test:editor`：11 项检查通过；包含四个原任务回归和四种自定义模板的完整结算与重置。
- DOM 交互流程连续 3 次通过：工具放置、参数修改、双方部署与战术、拖动、撤销/重做、试战/暂停/单步/恢复、非法导入、任务名转义、保存失败/导出、重新读取。使用真实编辑器代码、地形和模拟，渲染器与音频替换为测试桩；测试环境和脚本位于 `[local verification workspace]`，未加入项目依赖。
- `npm run build:offline`：类型检查、生产构建和内联资源生成通过；`试玩.html` 已更新。
